工具简介v—

        
在钢琴卷帘上编谱 → 输出手柄键位 → ESP32 模拟 Switch Pro 手柄演奏。

        
    
          
  • 曲谱编排：钢琴卷帘放置音符，支持 JSON / 文本 / MIDI 导入与导出。
    • 
          
  • 设备与测试：串口演奏、按键与摇杆调试、断连与回连。
    • 
          
  • 固件刷入：一键编译并上传 ESP32 固件。
